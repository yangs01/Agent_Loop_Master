# Claude Code 原理解析

> 一个面向工程师的系列教程：**重思路、轻细节**，用最短时间抓住 Claude Code 背后的架构思维。

## 这个系列在讲什么

不讲 API、不讲安装、不做逐行代码导读。整个系列只回答一个问题：

> **Claude Code 这一代 Agentic Coding 工具，背后的架构思维是什么？它做了哪些非显然的取舍，又为什么这么取舍？**

贯穿八篇的一条主线：

> **把复杂度交给更会增长的一方——模型与上下文，让框架保持最薄。**

每一篇都围绕"一个核心设计决策"展开，并与常见替代方案（ReAct / AutoGPT / LangChain / 多 Agent 框架 / 向量检索等）对比。

## 适合谁读

- 已经懂 LLM / Agent 基础，想看架构层面的取舍与判断
- 正在或打算自己构建 Agent，想避开"过度工程"的坑
- 想建立对这一代 Agent 演进方向的"坐标感"

## 怎么读

- **赶时间**：读第 1 篇 + 第 2 篇，就能掌握约 80% 的架构思维。
- **想要洞察**：第 5 篇（grep vs 向量检索）是最反直觉、信息密度最高的一章。
- **系统理解**：按序读完八篇，每篇结尾都为下一篇埋了钩子，连起来是完整的一条逻辑线。

## 一句话总纲

> **Claude Code 的每一个"简单"，背后都是一次"把复杂度交给更会增长的那一方"的主动选择。**
